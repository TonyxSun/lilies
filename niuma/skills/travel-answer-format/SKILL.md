# Travel answer format

For every option you recommend:
1. Name, a one-line reason it fits, and the price.
2. A Google Maps link to the exact place (for a multi-stop day, one Maps route link with all stops).
3. A booking link with the user's dates, party size, and origin/destination already filled in (Google Flights, hotel site, Resy/OpenTable, etc.).
4. One photo of the place, downloaded and attached.
5. Temperatures in °C.

Pricing rules:
- Only quote a price you checked live on the booking page or the property's own site, and give the check time (e.g. "checked 3:40pm"). Use the all-in total for the user's dates when the site shows it.
- Anything not live-checked (search-engine snippets, old quotes) is labeled "estimate".
- If a site blocks the check (bot wall, login), say it was blocked rather than calling it unavailable or sold out.
- Never book or pay; booking stays with the user.

Before sending:
- Open every link and confirm it loads the right place with the dates applied. Drop or replace any dead link; never send an unverified one.

Format each option as one line: `- [Name](booking-url), price (checked time or estimate), note — [Map](maps-url)`, with the photo below the list.
