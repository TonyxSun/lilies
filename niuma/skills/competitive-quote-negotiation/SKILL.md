# Competitive quote negotiation

Goal: run a **written bidding loop** that lowers OTD toward (or under) the user’s target, without autonomous blunders on threads, calls, or credit apps.

## Preconditions
- Quote sheet with ≥2 comparable written OTDs (same product definition).
- Target OTD + walk-away already set.
- User wants negotiation help; **every consequential outbound reply needs their yes** (draft → approve → send). Standing “handle dealer email” permission must be unmistakable and scoped; when unsure, draft.

## Loop
1. **Normalize offers.** Recompute each OTD with the same fee rules. Strip or challenge non-removable-looking add-ons in writing. Flag quotes that expire today or use “if you buy tonight” pressure.
2. **Pick leverage.** Send the **lowest credible OTD** (PDF or clear itemization) to the next-best seller: “Can you beat this OTD on [VIN/stock]?” Do not attach the user’s target or walk-away.
3. **One variable at a time.** Price/OTD first. Trade-in and APR only after sale price is locked (or in a clearly separate thread the user opened).
4. **Monitor inbound on a schedule** the user asked for (or a weekday daytime routine). On each new dealer message: summarize, update the quote sheet, draft the next leverage reply, **stop for approval**. Never reply from the wrong thread or to the wrong seller.
5. **Calls and texts.** Default script for the user: decline voice, push to email. Do not have the agent place negotiation calls. If the user forwards a text, answer in draft form only.
6. **Stop rules.** Hand back to the user when: (a) OTD ≤ target, (b) best offer is still above walk-away and sellers stall, (c) credit app / e-sign / deposit is requested, (d) a seller demands same-day close with incomplete itemization. Agents do not submit credit apps, sign, or pay deposits.
7. **Close hygiene.** Final comparison table: seller, unit, OTD, delta vs target, add-ons status, next human step. Delete or pause any “check email every few minutes” watch once the deal is won, lost, or paused.

## Do better than early agent demos
- **Recipient check** before every send: correct seller, correct VIN, correct thread.
- **No silent PII expansion** (phone, DOB, SSN, license, income) — those stay human-only.
- **Quote authenticity:** prefer dealer PDF / portal breakdown over a verbal number the user typed from a call.
- **Pressure tactics:** “extra $500 if you close tonight” is fine to use as a deadline *after* itemization is complete; never let urgency skip the fee line.
- **Audit trail:** keep the quote sheet and message drafts so another assistant or the user can resume cold.

## Anti-goals
- Fully autonomous negotiation without approval gates.
- Negotiating rate, trade, and price in one muddy email.
- Sharing one dealer’s customer PII or internal notes with another — share **price figures and unit IDs only**.
